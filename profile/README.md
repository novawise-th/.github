## 👋 เราคือใคร

**Novawise** คือแพลตฟอร์มรวมงานแข่งขันด้าน **หุ่นยนต์ · โค้ดดิ้ง · นวัตกรรม** สำหรับนักเรียน
เราเชื่อมนักเรียนจากทุกภาคเข้ากับเวทีที่เหมาะกับตัวเอง และเป็นระบบหลังบ้านให้ผู้จัดงานแข่งขันทำงานได้ครบในที่เดียว

> Novawise is Thailand's competition platform for student robotics, coding and innovation events — connecting students with the right stage, and giving organizers everything they need to run it.

## 🎯 ทำไปเพื่ออะไร

เราอยากให้ทุกการลงแข่ง **มีความหมายต่อไปได้จริง**

- เด็กทุกคนควรได้ **ลงสนามจริง** เจอคู่แข่งตัวจริง กรรมการตัวจริง และเพื่อนสายเดียวกันจากทั่วประเทศ
- ผลงานและใบประกาศควร **เก็บไว้ในที่เดียว** และ **ตรวจสอบได้** ใช้ยื่นพอร์ตต่อได้ทันที
- ผู้จัดงานควรได้ **โฟกัสที่ตัวงาน** ไม่ต้องเสียเวลากับระบบ เอกสาร และการตามสลิป
